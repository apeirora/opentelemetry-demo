The receiver keeps unsent records in memory, plus a circuit breaker (open_behavior: accept after 3 failures, 30s open). A restart drops that buffer. The sidecar exporter has sending_queue off. Verified audit logs use failover/grafana. The primary exporter posts to a proxy inside the Grafana network namespace, so docker stop grafana fails that export and the same batch is written to OpenSearch standby. Other app logs stay on the direct OpenSearch exporter. After docker start grafana, run docker restart grafana-primary-proxy.
